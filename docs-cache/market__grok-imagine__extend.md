# Grok Imagine - Video Extend

## OpenAPI Specification

        off.


        ## Task ID Source


        task_id must be a successful grok-imagine/text-to-video or
        grok-imagine/image-to-video task. You can create such videos with:


        <Card title="Generate videos First" icon="lucide-video"
        href="/market/grok-imagine/text-to-video">
          Use the text-to-video model to create videos in order to obtain scalable task IDs
        </Card>


        **How to obtain the task ID:**

        1. Use the [Text to Video API](/market/grok-imagine/text-to-video) to
        generate a video

        2. Extract the `taskId` from the API response

        3. Use this `taskId` as the `task_id` parameter in the extension request


        :::info[Information]

        Only videos generated by **Kie AI models** can be extended. External
        videos are not supported.

        :::


        ---


        :::tip

        Billed only for the newly added seconds (extend_times), at the
        resolution of the source video. For current prices, see
        [kie.ai/pricing](https://kie.ai/pricing).

        :::


        ## Query Task Status


        After submitting the extended task, use the unified query endpoint to
        check the progress and obtain the results:


        <Card title="Get Task Details" icon="lucide-radar"
        href="/market/common/get-task-detail">
          Learn how to query task status and retrieve generation results.
        </Card>


        :::tip[Pro Tip]

        For production use, we recommend using the `callBackUrl` parameter to
        receive automatic notifications when the extension completes, rather
        than polling the status endpoint.

        :::


        ---
